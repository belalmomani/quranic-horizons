# مواصفات صور المشاهد النهائية
1. **صورة منفصلة لكل لقطة** (ملف واحد لكل صورة، لا لوحة مجمَّعة).
2. **الدقة:** عرض ≥ 1080 px، ويُفضَّل 9:16 عموديًا (1080×1920 أو أعلى). المدقّق يرفض الاعتماد إن قلّ العرض عن 1080.
3. **بلا أي نص ولا أرقام ولا شارات داخل الصورة.** نص الآية يُرسم دائمًا من نص Tanzil. (في الصورة المجمَّعة المرسلة كُتبت الآية 2 «مبلك»، فقُصّ النص.)
4. **ترك الثلث السفلي هادئًا/داكنًا** لأن نص الآية والأزرار تُعرض فوقه.
5. **الآية 4 تحتاج لقطتين:** (أ) الوسوسة عند الغفلة، (ب) الاختفاء عند ذكر الله (الدخان ينحسر والرجل يذكر ربه).
6. **الآية 6 لقطتان منفصلتان:** الجنّة (الشكل الدخاني) ثم الناس (الهمس البشري).
7. لا تجسيد لله ولا لنبي. الأشخاص عامّون بلا هوية.
8. توثيق الأداة/المصدر وشروط الاستخدام لكل صورة قبل التوزيع.
9. الأسماء: `n1.jpg` … في `content/bootstrap/modules/114/img/` ثم تشغيل `tools/build_content.py` (يحسب البصمات ويحدّث الكتالوج).
